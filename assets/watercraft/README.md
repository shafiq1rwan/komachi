# Watercraft

From Kenney's **Watercraft Kit** (https://kenney.nl, CC0 1.0). `boat-fishing-small.glb` is the boat that
circles the island (`src/sea.js`, scaled 0.23, textured with `Textures/colormap.png`). `boat-row-small`,
`boat-sail-a`, `buoy` and `buoy-flag` are kept for the pier and the fishing phase; the rest of the kit was
left out.
